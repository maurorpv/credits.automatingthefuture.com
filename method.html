How this list is made

This site exists because other “AI perks” pages sell access to public information. We publish the same class of notes, for free, with the marketing stripped out.

What gets listed

A program is in the live guide only if an unincorporated person can start it with a personal email (and sometimes a card). If the official page requires a registered company, accelerator seat, or VC referral, it goes in “Skip for now” or a future guide.

What we refuse to do

  • Sum every program into “$X million available.”
  • Call a how-to guide a credit.
  • Put official links behind a signup or a price.
  • Guarantee approval.
  • Keep a listing after we know the official page died — we mark it stale or remove it.

Dates

Every card on the homepage was last reviewed on 4 September 2026. Dollar figures that circulate on blogs are labeled “often cited” because providers change promotions without a press release. The official button is the source of truth.

Corrections

Open an issue or pull request on the GitHub repo. Prefer a link to the provider’s current page over a screenshot of a third-party directory.
